# Security policy

Inkflow is entirely local and does not make network requests. It uses only the Obsidian Vault API to read the active Markdown note and to write its own `.ink.json` and PNG assets.

Please report a suspected vulnerability privately to the repository maintainer rather than opening a public issue. Include the Inkflow version, Obsidian version, platform, and a minimal reproduction. Supported security fixes are released for the latest version.
